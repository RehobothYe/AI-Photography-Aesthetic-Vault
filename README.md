# AI Visual Style Analyzer

An AI-powered framework for analyzing visual aesthetics, photography style, and cinematic language.

## Overview

AI Visual Style Analyzer helps creators understand the visual DNA behind images.

Instead of only describing what appears in an image, this framework analyzes the creative decisions behind it:

- Composition
- Camera language
- Lighting
- Color system
- Texture
- Cinematic atmosphere

It transforms visual references into structured creative insights and AI generation prompts.

## Applications

- AI image creation
- Photography research
- Film visual development
- Creative direction
- Brand visual analysis
